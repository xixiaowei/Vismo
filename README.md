# Geopelia Bongocat Desktop Pet

A completed custom Live2D Bongocat desktop pet project. 

> 🌐 **Official Website**: [Visit Website](https://bongocat.pet/)
> 💻 **Open Source Repo**: [View on GitHub](https://github.com/vladelaina/BongoCat)

##  Project Structure

-  **`Ready_to_Use/`**
  Import the entire folder into the Bongocat software to use the model directly.

-  **`Live2D_Source/`**
  The Live2D Cubism source files. You can modify the model in the software, including but not limited to customizing mouse tracking styles and adding expressions. 

-  **`resources/`**
  Contains image assets and configuration files.

>  **Warning**
> **Do not add malicious content to the model.**

##  How to Use
1. Download the Bongocat base software from the [official website](https://bongocat.pet/) or [GitHub](https://github.com/vladelaina/BongoCat).
2. Download the folder inside `Ready_to_Use/` from this repository.
3. Open your Bongocat software and import the downloaded folder.
